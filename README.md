# BIS@80 Final Five

A web page for reviewing the BIS@80 logo entries and choosing a final 5.

## Files

| File | What it is |
|---|---|
| `index.html` | The page itself. It works as soon as it is uploaded. |
| `source.html` | An untouched copy of the page with the original mygov.in links. GitHub uses it to rebuild `index.html`. |
| `download_images.py` | Downloads every logo into an `images` folder. GitHub runs it for you. |
| `.github/workflows/fetch-images.yml` | Tells GitHub when to run the download. |
| `.nojekyll` | Lets GitHub Pages serve the files as they are. |

## How to choose your final 5

1. **Review.** Click **▶ Review one by one**. Press **S** to shortlist an entry or **X** to set it aside; either key moves you to the next entry. The arrow keys move without deciding.
2. **Narrow down.** Set **Show** to **Shortlisted**. Tick **⇄ Compare** on up to 6 entries, then click **Compare** to see them side by side.
3. **Pick and rank.** Click **+ Add to final** on your favourites. In **View final 5**, use **Rank higher / Rank lower** to put them in order.
4. **Export.** Click **Export** to copy the list or download a spreadsheet (.csv).

Your decisions are saved in this browser only. Use **Back up my decisions** to save them to a file, and **Restore a backup** to load them in another browser or on another computer.
